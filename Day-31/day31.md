# Day 31 – AI Supply Chain Control Tower

## Project
AI Supply Chain Control Tower

## Overview

Built an interactive Operations Control Tower simulation using HTML, CSS, and Vanilla JavaScript.

The simulator places the user in the role of Head of Operations responsible for managing real-time supply chain disruptions.

## Features

- Live KPI Dashboard
- Operational Alerts
- Multiple Decision Options
- Countdown Timer
- Event Log
- Final Performance Report
- Responsive Dark UI
