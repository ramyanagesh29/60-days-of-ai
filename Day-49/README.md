# Personal AI Playbook

A single-file HTML app that turns how you actually use AI into reusable, editable workflow systems — instead of rewriting prompts from scratch every day.

## What it does
- **Prompt Builder** — assemble prompts from 9 labeled building blocks (role, objective, context, constraints, reasoning strategy, output format, tone, examples, quality checks) with a live preview
- **Loop Builder** — turn any prompt into a self-correcting autonomous loop by defining goals, evaluation criteria, improvement strategy, stop conditions, and safety rules
- **My Workflows** — save, search, filter, favorite, duplicate, and edit reusable workflows (8 pre-built + unlimited custom ones)
- **Categories** — workflows grouped by task type: Coding & Builds, DSA & Placement Prep, Content Creation, Career Documents, Research & Comparison
- Import/export as JSON, dark/light mode, keyboard shortcuts, onboarding

## Tech stack
HTML, CSS, JavaScript (vanilla) — zero external dependencies, single file, works fully offline. Data persists via browser local storage.

## How to run
Open `personal-ai-playbook.html` in any browser. No build step, no server.
